## 语言约定

- 中文版本是默认入口和内容源，新增文档先用中文完成。
- 面向用户的重要文档保留中英文版本；英文文件使用 `.en.md` 后缀。
- 双语页面在顶部互相链接，修改时同步命令、版本、能力边界和安全承诺。
- 新增普通文档优先使用中文文件名；约定入口名、ADR 编号、工具路径和已有稳定链接可保留英文文件名。
- 尚未提供英文版的内部文档以中文原文为准，不用机器占位译文冒充已维护的英文文档。
