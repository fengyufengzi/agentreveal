# AgentGuard macOS Desktop Pilot 试用说明

> 状态：非 CLI Desktop cohort 模板。只有收到已通过 Developer ID 签名、Apple 公证与 Gatekeeper 验证的
> Apple Silicon DMG 后才能开始；当前未签名开发包不得发给试用者。
>
> 预计用时：15–20 分钟。整个主流程不要求打开终端或安装 Node.js。

## 1. 开始前

请准备：

- Apple Silicon Mac，macOS 12 或更高版本；
- 一个你日常使用 AI Coding Agent 的代码项目；
- 由邀请人提供的固定版本 DMG 下载链接和 SHA-256。邀请人负责先核对校验值，普通试用者无需使用终端。

不要使用持续变化的开发构建，也不要通过“仍要打开”、移除 quarantine 或关闭 Gatekeeper 来绕过系统验证。

## 2. 安装与首次启动

1. 打开受邀下载的 DMG；
2. 把 AgentGuard 拖到 Applications；
3. 从 Applications 启动 AgentGuard；
4. 确认系统没有要求绕过 Gatekeeper，也没有提示应用损坏；
5. 阅读首次页的本地运行、默认只读和零上传说明。

如果安装或启动失败，请停止，不要自行修改系统安全设置。只记录 macOS 版本、失败阶段和系统提示类别，
不要发送完整路径、配置或截图中的敏感信息。

## 3. 选择项目并扫描

点击“选择项目并开始扫描”，选择一个代码项目根目录。它通常包含 `.git`、`package.json`、
`pyproject.toml` 等标识；不要选择整个用户主目录、Documents 或包含多个项目的开发总目录。

项目扫描会：

- 解析项目内的 Agent 配置；
- 检查敏感文件名，但不读取普通源代码内容；
- 读取 Claude Code、Codex、CC Switch、OpenCode、Gemini CLI、OpenClaw 的常见本机配置；
- 全程在本机完成，不自动上传结果。

项目扫描不应请求与所选项目无关的“桌面”“文稿”“下载”等文件夹权限。如果出现，请记录请求了哪个
权限和当时所处步骤，不要为了完成试用盲目全部允许。

“扫描整台 Mac”是跨项目排查的次级入口，可能触发多个受保护文件夹权限请求，不是本轮非 CLI cohort
的必做步骤。

## 4. 完成一次行动闭环

扫描完成后，请在不接受陪同者指导的情况下完成：

1. 说出当前最优先处理的 Agent 和任务；
2. 打开该 Agent 工作区，查看风险原因和完整处理步骤；
3. 如果是 Claude Code 明文凭证任务，先点击“一键备份”，确认界面显示可恢复，再查看并执行迁移命令；
   其它任务先查看指引或 baseline 预览，不要求实际修改配置；
4. 如果你确实完成了 Claude 迁移，点击“复扫验证”，确认任务状态；再从全局整改区确认迁移备份仍可恢复。
   只有需要回退时才点击“一键恢复”，并确认恢复后明文任务重新出现；
5. 从顶部“报告与支持”导出 HTML 行动报告，并重新打开；
6. 导出脱敏诊断，打开 JSON 确认不包含项目路径、端点、task ID、配置内容或原始错误文本。

风险接受、Provider 信任和项目规则忽略不是必做项。只有理解其项目作用域、原因和撤销方式后才使用；
不要为了完成试用隐藏真实风险。

## 5. 反馈与安全边界

填写 [`pilot-feedback-form.md`](pilot-feedback-form.md) 时选择“macOS Desktop（非 CLI）”入口。反馈只写规则 ID、
任务状态和简短现象，不粘贴完整配置、报告、内部端点、API Key、Token、私钥或包含真实路径的截图。

以下任一情况都属于阻断问题：

- Gatekeeper 需要绕过；
- 项目扫描请求无关受保护文件夹权限；
- 输出或诊断出现明文凭证、项目路径、内部端点或配置内容；
- 应用崩溃、配置损坏、备份无法恢复；
- UI 把“已接受”或“已忽略”误导成“已修复”。

## 6. 卸载

1. 完全退出 AgentGuard；
2. 从 Applications 把 AgentGuard 移到废纸篓；
3. 弹出 DMG。

卸载应用不会自动删除已经导出的报告、`~/.agentguard` 审计状态、项目策略或整改备份。需要清理时由邀请人
参照 [`install-upgrade-uninstall.md`](install-upgrade-uninstall.md) 协助确认准确范围，不要求试用者执行陌生命令。
