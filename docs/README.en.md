## Language convention

- New documentation is written in Simplified Chinese first.
- Important user-facing documentation keeps Chinese and English versions; English files use the `.en.md` suffix.
- Bilingual pages link to each other and must keep commands, versions, capability boundaries, and security promises in sync.
- New ordinary documents prefer clear Chinese file names. Conventional entry points, ADR numbers, tool paths, and existing
  stable links may retain English file names.
